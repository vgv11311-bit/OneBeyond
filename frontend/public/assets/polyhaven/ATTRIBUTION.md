# Poly Haven sample-room assets

The following source assets are included only in the furnished sample room.
They are supplied by Poly Haven under CC0 1.0 Universal and retain their
original separate glTF files and 1K texture maps for browser performance.

- `painted_wooden_nightstand/` — Painted Wooden Nightstand, Kirill Sannikov
  https://polyhaven.com/a/painted_wooden_nightstand
- `desk_lamp_arm_01/` — Desk Lamp Arm 01, Kuutti Siitonen and Yann Kervran
  https://polyhaven.com/a/desk_lamp_arm_01

No Poly Haven live API is called by the app; these are locally stored copies.
