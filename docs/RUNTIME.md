# Runtime configuration

Use a separate CUDA environment compatible with the pinned upstream ReSplat
revision. Set source, weights and Python paths documented in README.md. The
checkpoint receipt is generated by scripts/prepare-resplat.py and verified at
runtime. COLMAP and FFmpeg are external executables, not Python dependencies.

For a remote worker, the existing adapter reads a private JSON file referenced
by ONE_BEYOND_RESPLAT_REMOTE_LEASE. Its required fields are project, zone, vm,
user, root, python, worker, host_key (a verified SSH SHA256 fingerprint), gcloud,
expires_at (timezone-aware ISO timestamp), and runtime_verified. Configure these
for your own existing machine; never commit this file. Inspect
backend/reconstruction/resplat_remote.py for optional camera preparation and
bounded session settings. This package includes no VM credentials or account
configuration and does not create/start a VM.

The main web environment needs frontend/node_modules for Three.js and Spark.
Run npm ci before starting the viewer. Large dependencies are omitted from the ZIP.
